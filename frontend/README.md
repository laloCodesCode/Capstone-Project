# How to run the frontend
  
<center>



# Important Notes!
- make sure the pip dependecies are installed ! Can be done by the following:
```
pip install -r requirements.txt
```
- make sure all node and expo dependencies are installed can be done by the following:
```
npm i
```
- Make sure you have IOS and or android emulator installed if one is not avaliable, follow the command line instruction to launch the frontend from a physical phone or a browswer

- generate the .env file (ask eduardo for them)
- run the backend logic
```
cd backend
```
```
fastapi dev backend/app/main.py
```
- run the frontend logic 
```
cd frontend
```
```
npx expo start
```
